# Critique Before Reading: De-duplicated Episode Ledger

## Counting rule

One continuous interaction about the same posted work counts once. A confirmed episode requires:

1. the assistant makes an adverse, limiting, or quality judgment about the work; and
2. later visible text establishes that the work had not been completely read, scanned, or verified at the time of that judgment.

An absent tool trace is not enough. User accusation alone is not enough. Repeated criticisms inside one unresolved review loop do not create new episodes.
